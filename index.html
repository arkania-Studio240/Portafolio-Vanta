    Nosotros

    Narrativa visual, en tres idiomas.

    Una miniatura tiene menos de un segundo para ganarse un clic. Partimos de una idea clara, construimos un punto focal y usamos contraste, emoción y tipografía para comunicarla al instante.

    Cada proyecto se diseña de forma nativa para inglés, español y portugués, para que cada audiencia vea la imagen pensada para ella, no solo una traducción.

    • Una idea, un punto focal
    • Contraste fuerte y tipografía legible
    • Nativo en cada idioma
